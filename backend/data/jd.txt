What Success Looks Like (Objectives)
As a Senior Software Engineer, you will solve the complex challenges of coordinating high-volume customer order lifecycles across a distributed e-commerce platform. Your work bridges the gap between fragmented microservices by engineering resilient orchestration workflows and designing scalable, highly secure APIs. By overcoming these technical hurdles and establishing robust integration pipelines, you will ensure a seamless, reliable purchasing experience for millions of consumers while driving architectural excellence.

Architect and implement resilient orchestration systems using AWS serverless technologies and containerized microservices to seamlessly manage the entire customer order lifecycle

Design scalable API specifications using OpenAPI/YAML while embedding advanced security protocols like OAuth and SAML to protect sensitive payment and logistics data

Drive technical excellence across the full API lifecycle and integration pipelines, contributing directly to departmental OKRs for system reliability and deployment velocity

Optimize complex database schemas, event-driven architectures, and caching strategies to continuously support high-concurrency e-commerce environments

Automate troubleshooting, enhance root cause analysis, and improve the efficiency of daily development workflows by leveraging Generative AI and LLMs
